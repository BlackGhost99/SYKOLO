# YEM Parents — lot Android 1 : entrée famille dédiée

L'entrée HTTPS `/?app=parents#/parents` réutilise la version web et le logo YEM. Elle masque les choix établissement, plateforme et démonstration. Une session de gestion déjà ouverte n'affiche aucun tableau de bord de gestion ; le parent peut la fermer puis se connecter en tant que parent. Les contrôles d'autorisation restent sur le serveur Django : ce paramètre d'interface ne constitue pas une frontière de sécurité. Le site général est inchangé.

Ce lot prépare le futur APK mais ne contient ni binaire APK, ni signature Android, ni notifications push natives. Le choix du conteneur Android doit être validé avec les fonctions de téléchargement PDF, téléversement de pièces, liens de récupération de compte, notifications et navigation externe. Ne pas activer les paiements réels en contournant les gates du serveur. Tester sur Android physique avant publication. Le développement reste sur une branche indépendante jusqu'à sa recette. Aucun changement de base de données.

## Lot 2 — conteneur Android

L’APK de test utilise uniquement `https://yem-api.onrender.com/parents-app/`. Une ancienne version du serveur ne possède pas cette route et affiche une erreur, pas l’interface générale. Projet Java/Android natif, rendu WebView des écrans YEM, Android 8+ (API 26), SDK 35, AGP 8.13.2 et Gradle 8.13. HTTPS obligatoire, filtre strict de l’origine et du chemin principal, aucun pont JavaScript natif, cookies tiers interdits, erreurs SSL jamais ignorées, sauvegarde Android désactivée, protection des captures d’écran. Aucun secret marchand dans l’APK. Les autres liens sont actuellement refusés. Les PDF, pièces jointes, liens externes et notifications natives restent à intégrer dans un lot séparé. L’APK debug GitHub Actions est uniquement destiné aux essais, non signé pour commercialisation ; la clé de production doit rester hors dépôt. Compilation locale : JDK 17, Gradle 8.13, SDK Android 35, puis `cd android && gradle :app:assembleDebug`. Le workflow génère le fichier APK en artefact si la compilation réussit. Installer seulement après déploiement de la route et vérifier sur appareil réel.\n
